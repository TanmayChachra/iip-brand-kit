# ISAPUR Industrial Park (IIP): brand project

Start with `CLAUDE.md` (rules for every chat), then `00_ISAPUR_KNOWLEDGE.md` (single source of truth, never delete or move, append to its change log). Open work: `TODOS.md`. History: `CHANGELOG.md`.

## Folder map
| Path | What | Status |
|---|---|---|
| `CLAUDE.md`, `00_ISAPUR_KNOWLEDGE.md`, `TODOS.md`, `CHANGELOG.md` | Project context, facts and decisions, open work, history | Permanent, keep current |
| `Brand-Kit/` | The kit. `IIP-master-assets.svg` is the one master file (brand book artboards plus every SVG asset). See its README | Current |
| `docs/` | Published copy for GitHub Pages: `index.html` (brand kit), `brief.html` (brand brief), downloads. Generated by `Brand-Kit/_build/publish.py` | Generated |
| `Isapur-Poster/` | Poster. `03_Design/00_LATEST...pdf` is the print file, `01_LATEST...svg` the master, older versions in `_archive/` | Current |
| `AI-Assets/` | Phase 3 only: everything AI generated goes here, never in the kit | Not started |
| `IIP Assets/` | Supplied logo files | Source, do not edit |
| `References/` | Competitor photos, inspiration ads, the final ChatGPT thread images | Reference |
| `Archive/` | Old work: `work-v1/`, `docs-site-v1/`, `kit-v1-*` (old templates, exports, mockups, pptx), moodboards, process log. Git ignores it | Archived |

## Rebuild
```
python Brand-Kit/_build/build_all.py   # every SVG, PDF, PNG, master file, print colours
python Brand-Kit/_build/publish.py     # page, brand book PDF, brief, copy to docs/
```

## Rules
Logo never changes. English only. Taglines are adaptive (two approved lines). Developer is not named. No claim without proof on file. Online images are WEBP. No em dashes, no co-author lines in git.
