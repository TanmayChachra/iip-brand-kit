# IIP website (Astro)

Static site, Astro 7, Cloudflare Pages target. Rules: `02_Website/DESIGN-DIRECTION.md`. Page list: `02_Website/pages.md`. Tracking: `04_Analytics/event-spec.md`.

## Run
```
cd 02_Website/site
npm install
npm run dev        # http://localhost:4321
npm run build      # output in dist/
```
Node 22.23.4 or newer.

## Env vars (copy `.env.example` to `.env`, none are secrets)
- `PUBLIC_SITE_URL` public URL, used for canonicals and the sitemap.
- `PUBLIC_GTM_ID` GTM container ID. Without it no tag script is added.
- `PUBLIC_FORM_ENDPOINT` form backend URL (Cloudflare Pages Function or a form service). Without it the form falls back to mailto.
- `PUBLIC_WHATSAPP` WhatsApp number with country code, digits only.

## Deploy to Cloudflare Pages (owner account)
Connect the repo, root directory `02_Website/site`, build command `npm run build`, output `dist`, Node 22. Set the env vars above. Then update `public/robots.txt` and `public/llms.txt` with the real domain and submit `sitemap-index.xml` in Search Console and Bing.

## Content
Pages are Markdown in `src/content/pages/` (frontmatter: title, description, h1, lead, pageType, draft, schema, faq). Posts in `src/content/posts/`. `draft: true` excludes a page from the build and the sitemap. Placeholder copy was generated by `02_Website/qa/gen_content.py` and will be replaced by `06_Content/website-copy/`.
Allowed claims only (see the Claims section of DESIGN-DIRECTION.md). Real photos go in `public/img/` and replace the illustrations.

## QA
`python 02_Website/qa/qa.py` (links, H1, canonical, claim scan, screenshots) after `npm run build`.
